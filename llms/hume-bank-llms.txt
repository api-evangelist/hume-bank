# Hume Bank

> Hume Bank is a customer-owned (mutual) Australian bank headquartered in Albury, New South Wales, and an authorised deposit-taking institution (ADI) participating in Australia's Consumer Data Right (CDR / Open Banking). It exposes a public, unauthenticated Product Reference Data (PRD) API built to the Consumer Data Standards, covering its retail and business deposit, lending, and credit card products.

## APIs

- [Hume Bank CDR Product Reference Data API](https://www.humebank.com.au/about-hume-bank/customer-resources/open-banking-products-api): Public PRD API returning Hume Bank's openly offered banking products (rates, fees, eligibility). Base: https://ibankob.humebank.com.au/OpenBanking/cds-au/v1/banking/products — send the mandatory `x-v` header (served x-v 4). No authentication required.
